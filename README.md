# Modern PHP

A modern PHP learning repository focused on PHP 8.2+, object-oriented programming, clean architecture, SOLID principles, design patterns, and real-world coding practices.

---

## Goals

* Master modern PHP fundamentals
* Learn professional OOP concepts
* Write clean and maintainable code
* Understand SOLID principles
* Practice design patterns
* Improve problem-solving skills
* Build strong backend engineering foundations

---

## Topics Covered

* PHP 8.2+ Features
* Variables & Data Types
* Functions & Arrays
* OOP in PHP
* Interfaces & Traits
* Namespaces & Autoloading
* Composer
* Exception Handling
* SOLID Principles
* Design Patterns
* Collections & Generators
* Enums & Attributes
* File Handling
* Database Basics
* Mini Projects
